# Font locali

Inter, Plus Jakarta Sans e Fraunces distribuiti dal repository ufficiale google/fonts, licenze SIL Open Font License incluse. Font resi locali per evitare download Google durante la build. Sorgenti: https://github.com/google/fonts/tree/main/ofl/inter, https://github.com/google/fonts/tree/main/ofl/plusjakartasans, https://github.com/google/fonts/tree/main/ofl/fraunces.

I file WOFF2 Latin sono stati ottenuti una tantum dall’endpoint CSS ufficiale fonts.googleapis.com il 5 novembre 2026; non vengono scaricati durante le build. Quattro file variabili: Inter normale, Plus Jakarta Sans normale, Fraunces normale e corsivo. Peso complessivo circa 158 kB.
